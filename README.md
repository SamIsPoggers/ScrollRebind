# ScrollRebind - Forge 1.20.1 Mod

Allows you to rebind any keyboard key to a scroll direction 

## Usage

1. Open **Options → Controls**.
2. Find the **ScrollRebind** category.
3. Bind **Scroll Up** and/or **Scroll Down** to any key.

## Building

Requires **JDK 17** and **Gradle 8+**.

```bash
./gradlew build
```

The built jar will be in `build/libs/`.

## Requirements

- Minecraft **1.20.1**
